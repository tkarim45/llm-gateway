LLM Gateway — Architecture

Production LLM API gateway: API-key auth, per-tenant rate limiting + token quotas, ordered provider failover, SSE streaming, cost metering + audit.

Admit

  • • per-tenant API-key auth
  • • token-bucket rate limiting → 429
  • • token quotas → 402 on exceed

Route

  • • ordered provider failover (verified live)
  • • dead primary → served by Bedrock on attempt 2
  • • SSE streaming passthrough

Meter

  • • per-tenant cost metering ($/tokens)
  • • /v1/usage endpoint
  • • append-only JSONL audit (prompts never logged)
